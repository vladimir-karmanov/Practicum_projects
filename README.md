### 🏠 Анализ рынка недвижимости (СПб и ЛО)
**Задача:** Помочь агентству сформировать бизнес-стратегию на основе данных о спросе и сезонности.

**Инструменты:** PostgreSQL (выгрузка данных и обработка данных).

**Результат:** Выявлены ключевые сегменты жилья с устойчивым спросом и оптимальные сезоны для публикации объявлений. Рекомендации позволили агентству эффективнее распределять ресурсы.


### 🚀 Исследование рынка стартапов
**Задача:** Определить перспективные направления для инвестиций на основе структуры финансирования.

**Инструменты:** Python (pandas, numpy, matplotlib.pyplot, seaborn).

**Результат:** Выделены сегменты с устойчивым ростом и типы финансирования, коррелирующие с успехом проектов. Сформированы рекомендации по приоритизации инвестиций.


### 📖 Яндекс Книги: анализ продуктовых метрик
**Задача:** Оценить вклад авторов и произведений в долгосрочную ценность продукта (LTV, Retention).

**Инструменты:** Python (анализ когорт, A/B-тестов), SQL (расчёт метрик).

**Результат:** Выявлена группа авторов с лояльной аудиторией и высокой вовлечённостью. На основе A/B-теста даны рекомендации по улучшению UX.


### 🎭 Яндекс Афиша: драйверы выручки
**Задача:** Выявить наиболее прибыльные сегменты и ключевые драйверы выручки.

**Инструменты:** SQL (анализ каналов продаж), Python (статистический анализ), DataLens (дашборды).

**Результат:** Определены категории мероприятий и каналы, вносящие наибольший вклад в доход. Подготовлены рекомендации по оптимизации маркетинговых ресурсов с учётом сезонности.
